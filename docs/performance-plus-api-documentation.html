2. Tool Description

Performance Plus is an internal analytics platform developed by the notthesame agency to consolidate, monitor, and report on Google Ads campaign performance across all managed client accounts. It was built as an operational necessity to replace manual reporting processes that previously required exporting data from multiple interfaces.

The platform is used by the agency's internal team and by the agency's clients, who are granted secure, read-only access to their own campaign data via OAuth-authenticated accounts. Each client can only view data belonging to their own brand — no cross-account data exposure exists. It serves as a single source of truth for campaign KPIs, enabling faster decision-making and transparent live reporting for clients.

3. Google Ads API Usage

API UsedGoogle Ads API (REST / GAQL)
Access TypeManager Account (MCC) — agency manages multiple client sub-accounts
AuthenticationOAuth 2.0 with offline access (refresh token stored server-side via Firebase Cloud Functions)
Data PulledCampaign name, status, impressions, clicks, CTR, conversions, cost, ROAS — aggregated over custom date ranges
Query MethodGAQL via customers/{id}/googleAds:searchStream
Sync FrequencyOn-demand (manual sync) + scheduled daily via Firebase Cloud Scheduler
Data StorageGoogle Cloud Firestore (private, within the agency's Firebase project)
Data SharingNone — data is not shared with or sold to third parties

5. Data Handling & Privacy

  • All API credentials (Client ID, Client Secret, Developer Token, Refresh Tokens) are stored server-side using Firebase Secret Manager and never exposed to the client browser.
  • Campaign data is stored in a private Firestore database accessible only to authenticated agency team members.
  • No user personal data from end-consumers is collected or processed.
  • The platform does not make any changes to Google Ads campaigns — it is strictly read-only.
Note: Performance Plus is a client-facing reporting platform built by the notthesame performance marketing agency. Clients are invited via email and can only access data for their own brand. The agency manages all Google Ads accounts via MCC. The platform does not distribute or resell API access.
